# 檔案通 FileHub

Android 手機與平板的**檔案總管＋文件閱讀器**。

- 📁 管理手機裡的檔案：瀏覽、複製、移動、刪除、重新命名、搜尋，也能讀取 SD 卡和 USB 隨身碟
- 🗜️ 壓縮成 zip、解壓縮 zip / tar / gz 等格式
- 🧹 清理建議：找出大檔案、很久沒用的檔案和 App、已安裝過的安裝檔、空資料夾
- 📦 安裝檔分類：集中列出手機裡所有 APK，一鍵安裝
- ☁️ 從 Google Drive、OneDrive 等位置挑檔案開啟
- 📄 內建閱讀器：PDF、Word（docx）、Excel（xlsx / xls / csv）、PowerPoint（pptx）、圖片、文字檔、zip
- 🔗 其他 App（LINE、Gmail、瀏覽器下載…）開啟檔案時，可以選擇用「檔案通」開啟，也能設為預設
- 🔍 文件內搜尋（PDF、Word、Excel、PowerPoint、文字檔），重新打開會回到上次看到的地方
- 🗂️ 依類型瀏覽：所有文件、圖片、影片、音樂、壓縮檔集中列出
- 📊 儲存空間分析：看看空間被哪些類型和資料夾用掉
- 📶 Wi-Fi 傳檔：電腦用瀏覽器輸入配對碼，就能上傳或下載手機裡的檔案
- 📌 把常用的資料夾或檔案加到手機桌面
- 🔄 App 內檢查更新，有新版可以直接下載安裝
- 🔒 所有檔案都只在手機上處理，不會上傳到任何地方（網路只用來檢查和下載檔案通的新版本，以及你主動開啟的 Wi-Fi 傳檔）

> 這裡只提供安裝檔（APK），不包含程式碼。

## 下載

到右側的 **[Releases](../../releases/latest)** 下載最新版的 `filehub-v版本.apk`。

## 安裝

1. 用手機開啟上面的 Releases 頁面，點 `.apk` 檔下載。
2. 下載完成後開啟檔案。系統詢問時，允許瀏覽器（或檔案 App）**「安裝不明來源的應用程式」**。
3. 按「安裝」。

## 第一次使用

開啟「檔案通」後，依照畫面指示授予檔案存取權：

- **Android 11 以上**：會開啟系統設定頁，請打開「允許存取所有檔案」，再按返回鍵。
- **Android 8 – 10**：會跳出詢問視窗，請按「允許」。

## 更新

v1.2.0 起，App 開啟時會自動檢查新版本（每天最多一次），有新版會在首頁提示，按「下載並安裝」即可。也可以在右上角「關於檔案通」手動檢查，或關閉自動檢查。

安裝時如果出現 Google Play 安全防護的「建議掃描」提示，可以選擇掃描，或展開「更多詳細資料」選擇「不掃描直接安裝」。

## 設為預設的開檔程式

在其他 App 點開檔案時，系統會詢問要用哪個 App 開啟，選「檔案通」再按「一律使用」即可。

## 系統需求

Android 8.0 以上的手機或平板。

## 已知限制

- Word / Excel / PowerPoint 的排版會盡量接近原檔，但不會完全一樣。
- 舊版格式 `.doc`、`.ppt` 只顯示文字內容。
- 不支援 rar、7z 壓縮檔；NTFS 格式的外接硬碟大部分手機本身就無法讀取。
- 「很久沒用的 App」需要到系統設定開啟「使用情形存取權」。
- 只能閱讀，不能編輯。
